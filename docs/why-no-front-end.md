# Why no front end

Document production is a template, the records to merge, a review and an output. An operator can run that work through one CLI, with read-only reports showing the queue and evidence. The database keeps each version so a new question can join information across jobs and reviews.

A visual document product also provides a layout designer, exact Word and PDF rendering, Salesforce buttons, browser previews, mobile access, signatures and connected delivery. This base provides none of those interfaces. It cannot reproduce arbitrary Office layouts, work offline against a shared database, or drag and drop document elements. Word import extracts paragraph text only; outputs are HTML drafts.

The base is useful to a trusted operator producing recurring confirmations, renewal letters and record summaries. Enterprise DNA builds the agreed interfaces, exact formats, connections and access rules around the same records. A browser is for reading the generated document, not changing records.
